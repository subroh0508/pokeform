- **cosmetic と新規 distinct 種を区別し安全側に倒す**: base も languages に無い場合は cosmetic でなく**新規 distinct 種**と判断し畳まず forme id を返して generate で名前欠落として顕在化させる（推測で base へ潰さない loud 側）。
